Quick Crypt encourages you to use PRF-capable passkeys for stronger protection of your data. While passkeys without PRF remain secure, PRF is a significant security upgrade.

The PRF extension is widely supported, but not yet universal. The list of PRF-compatible systems is growing rapidly and includes: 1Password, YubiKey, Apple Passwords, Windows Hello, Google Password Manager, Keeper, Proton Pass, SoloKeys, and Dashlane. A notable exception is Bitwarden, which does not yet support PRF for the passkeys it manages (add your vote to the feature request).

You may select a different passkey or continue with standard protection.
